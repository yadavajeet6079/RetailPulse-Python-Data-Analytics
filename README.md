# 📊 RetailPulse — Python-Powered Data Analytics

### Transforming Retail Data into Actionable Insights

RetailPulse is a Python-based data analytics project that explores retail sales data using statistical analysis, data cleaning, exploratory data analysis (EDA), and data visualization.

The project contains nine tasks designed to analyze sales performance, identify patterns, detect outliers, study relationships between variables, and generate data-driven business recommendations.

---

## 🎯 Project Objectives

- Analyze retail sales data using Python.
- Calculate statistical measures and variance.
- Explore correlation and probability.
- Identify potential outliers.
- Create informative charts using Matplotlib and Seaborn.
- Clean and prepare data for analysis.
- Perform exploratory data analysis (EDA).
- Identify sales trends and business insights.
- Generate recommendations based on the analysis.

## 📌 Project Tasks

### Task 1: Statistical Analysis
Calculate descriptive statistics and explore the distribution of sales data.

### Task 2: Variance Analysis
Calculate and visualize variance to understand the spread of numerical data.

### Task 3: Correlation and Probability
Explore relationships between numerical variables and perform probability-related calculations.

### Task 4: Outlier Detection
Identify unusual observations in the dataset using statistical techniques.

### Task 5: Data Visualization with Matplotlib
Create charts to represent sales data and communicate patterns visually.

### Task 6: Statistical Visualization with Seaborn
Use count plots, box plots, correlation heatmaps, and pair plots to explore the dataset.

### Task 7: Data Cleaning
Prepare the dataset for analysis by addressing data quality issues and saving a cleaned dataset.

### Task 8: Exploratory Data Analysis (EDA)
Generate summary statistics, analyze sales by category and region, study correlations, and identify business insights.

### Task 9: Business Recommendations
Evaluate category and regional performance and prepare recommendations based on the analysis.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/yadavajeet6079/RetailPulse-Python-Data-Analytics.git
```

### 2. Navigate to the project directory

```bash
cd RetailPulse-Python-Data-Analytics
```

### 3. Install the required libraries

```bash
python -m pip install pandas numpy matplotlib seaborn
```

---

## ▶️ How to Run the Project

Run the following commands from the project root directory.

### Step 1: Run Task 1

```bash
python tasks/task1_statistics.py
```

### Step 2: Run Task 2

```bash
python tasks/task2_variance.py
```

### Step 3: Clean the Dataset

Run Task 7 before Tasks 3, 4, 5, 6, 8, and 9.

```bash
python tasks/task7_data_cleaning.py
```

### Step 4: Run Task 3

```bash
python tasks/task3_correlation_probability.py
```

### Step 5: Run Task 4

```bash
python tasks/task4_outliers.py
```

### Step 6: Run Task 5

```bash
python tasks/task5_matplotlib.py
```

### Step 7: Run Task 6

```bash
python tasks/task6_seaborn.py
```

### Step 8: Run Task 8

```bash
python tasks/task8_eda_insights.py
```

### Step 9: Run Task 9

```bash
python tasks/task9_recommendations.py
```

**Note:** Task 7 should be run first whenever the cleaned dataset needs to be regenerated.
